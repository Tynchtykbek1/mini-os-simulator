# Mini OS Simulator

A small Python project for demonstrating Operating Systems concepts.

## Implemented Features

- FCFS (First-Come, First-Served) CPU Scheduling

## Files

- `models.py`: contains the `Process` model.
- `cpu_scheduling.py`: contains the FCFS scheduling algorithm.
- `main.py`: creates sample processes, runs FCFS, and prints results.

## Run

```bash
python main.py
```
